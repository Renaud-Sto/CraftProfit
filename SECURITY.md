# Security policy

CraftProfit is a World of Warcraft addon: it runs inside the game client, reads only game data, makes no network request and never presses a purchase button. Its saved variables hold prices and your pinned recipes, nothing personal.

If you find a problem that could harm a player (for example an action performed without their input, or a way to make the addon taint or block a protected Blizzard action), please **do not open a public issue**. Use GitHub's private vulnerability reporting (the *Security* tab of this repository, *Report a vulnerability*). You will get an answer within a few days.

Ordinary bugs go through the [issue tracker](https://github.com/Renaud-Sto/CraftProfit/issues).
